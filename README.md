# rock-paper-scissors

A command-line Rock Paper Scissors game built using Python. The player competes against the computer, and the first to reach 3 points wins the match.

## Features

- User vs Computer gameplay
- Random computer choices using Python's `random` module
- Score tracking for both player and computer
- First-to-3-points winning system
- Draw detection
- Simple command-line interface

## How to Play

- Enter `R` for Rock
- Enter `P` for Paper
- Enter `S` for Scissors

The game continues until either the player or the computer reaches 3 points.

## Requirements

- Python 3.x
